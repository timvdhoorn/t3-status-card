# t3-status-card

Task status card for T3 Code `html_render` frames. Loaded from jsDelivr so each render only sends data.

```html
<script src="https://cdn.jsdelivr.net/gh/timvdhoorn/t3-status-card@v1/s.js"></script>
<script>S({t:"Task",r:"not released",p:3,n:"Execution",s:"a",x:"bun test"})</script>
```

See the header of `s.js` for fields.
